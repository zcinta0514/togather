## 7. GitHub Pages 部署决策

2026-09-19 用户确认继续使用 Cloudflare Pages，不切换到 GitHub Pages。GitHub 子域名方案仅作为备选：若以后采用，必须改成“GitHub Pages 静态前端 + Cloudflare API/D1”混合架构，不能把当前项目原样上传后直接运行。

用户曾提出只上传到 GitHub 并使用 GitHub 子域名。当前项目不能直接作为 GitHub Pages 纯静态站点运行，因为它依赖：

- /api/* 服务端接口
- Hono Worker
- Cloudflare D1
- 活动创建、投票、结果计算和定案的共享服务端状态

如果坚持 GitHub Pages，需要另行选择后端：GitHub Pages 只托管前端、后端继续放 Cloudflare / 其他服务，或重写成纯静态本地应用。这是架构决策，不是简单改部署脚本。
